# Thonloader

A simple YouTube video downloader built with Python and Flask.

## Features
- Video preview before downloading
- Quality selection (1080p, 720p, 480p, audio only)
- Downloads directly to your browser
- Playlist detection warning

## Requirements
- Python 3
- ffmpeg

## Installation

1. Clone the repository
   
   git clone https://github.com/eleazarnv/thonloader.git

2. Install dependencies

   pip install flask yt-dlp

3. Run the app

   python app.py

4. Open your browser at http://127.0.0.1:5000
